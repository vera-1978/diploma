# diploma

# Автоматизация тестирования веб-ресурса «Кинопоиск» (UI + API)

Данный проект представляет собой комплексное решение по автоматизации тестирования критического пути (Smoke UI) веб-версии онлайн-кинотеатра **Кинопоиск**, а также верификации интеграционных контрактов его бэкенда (позитивные и негативные API сценарии).

## Стек технологий
* **Язык программирования:** Python 3.14+
* **Тестовый фреймворк:** PyTest 9.1.1+
* **Автоматизация UI:** Selenium WebDriver
* **Автоматизация API:** Requests
* **Отчетность:** Allure Framework & Allure-Pytest
* **Конфигурация:** Python-dotenv (управление секретами)

---

## Структура проекта
* `API/` — папка с автоматизированными API-тестами.
  * `test_positive.py` — позитивные сценарии проверки контрактов.
  * `test_negative.py` — негативные сценарии (валидация параметров и авторизации).
  * `PageApiKinopoisk.py` — базовый класс-клиент для отправки HTTP-запросов к API.
* `UI_kinopoisk/` — папка с автоматизированными UI-тестами на базе Selenium.
  * `test_ui_kinopoisk.py` — сценарии проверки интерфейса (поиск, карточки, меню).
* `.env` — файл с локальными переменными окружения (не коммитится в Git).
* `allure-results/` — папка для сбора результатов тестирования (создается автоматически).

##  Инструкция по установке и настройке

### 1. Клонирование репозитория
Откройте терминал (или Git Bash) и выполните команду:
```bash
git clone <ссылка_на_ваш_репозиторий_github>
cd diploma
```

### 2. Установка зависимостей
Убедитесь, что у вас установлен менеджер пакетов `pip`. Для установки всех необходимых библиотек выполните:
```bash
pip install pytest selenium requests allure-pytest python-dotenv faker
```

### 3. Настройка переменных окружения (.env)
Для работы API-тестов необходимо настроить авторизационный токен. 
1. В корневой директории проекта (`diploma`) создайте файл с именем `.env`
2. Добавьте в него следующую строку, указав ваш личный токен от Кинопоиска:
```env
KINOPOISK_API_KEY=ваш_секретный_токен_api
```

## Инструкция по запуску тестов

Все команды необходимо выполнять из **корневой директории** проекта (`diploma`).

### Режим 1: Полный запуск всех автотестов (UI + API)
```bash
pytest --alluredir=allure-results
```

### Режим 2: Запуск только UI-тестов (Интерфейс)
```bash
pytest UI_kinopoisk/test_ui_kinopoisk.py --alluredir=allure-results
```

### Режим 3: Запуск только API-тестов (Бэкенд)
Вы можете запустить всю папку с API-тестами:
```bash
pytest API/ --alluredir=allure-results
```
Или конкретный файл (например, позитивные сценарии):
```bash
pytest API/test_positive.py --alluredir=allure-results
```

### Режим 4: Запуск конкретного тест-кейса по его названию
```bash
pytest -k "test_api_key_unauthorized" --alluredir=allure-results
```

## Просмотр отчетов Allure

После завершения любого тест-рана вы можете сгенерировать и открыть интерактивный отчет в браузере одной командой:
```bash
allure serve allure-results
```
